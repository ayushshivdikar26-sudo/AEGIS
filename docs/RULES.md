## 4. Permission Creep Assessment Rules

- **Delta Review Threshold:** 5 points
- **Delta Significant Threshold:** 15 points

### Creep Outcome Classifications
1. **Significant increase in assessed permission exposure:**
   - Score delta >= 15 points, OR
   - Any added capability has weight 5, OR
   - Host pattern broadened to a weight-5 tier (`all_sites`), OR
   - Risk score crossed threshold into High level (> 69).
2. **Permission changes require review:**
   - Score delta >= 5 points, OR
   - Any added capability has weight >= 3, OR
   - Host pattern broadened to a wider tier, OR
   - Any unrecognized capability added.
3. **No significant permission creep detected:**
   - All other changes (removals, or low-weight additions with delta < 5).
